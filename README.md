# rotlib

This is a collection of functions allowing interconversion between four
commonly used rotation representations: 

* Quaternion
* Axis-angle
* Direction cosine matrix
* Euler angles

**Axis-angle** The axis must be a unit vector and the angle should be in [0,
$\pi$).

**Euler angles** We consider six sequences of Euler angles with non-repeated
axes: (1) XYZ, (2) XZY, (3) ZXY, (4) ZYX, (5) YZX, and (6) YXZ. For example,
the sequence 'XYZ' (in the world frame) = [*phi*, *theta*, *psi*] signifies
first rotation by *phi* about X, second rotation by *theta* about Y, and the
third rotation by *psi* about Z axis of the world (i.e. fixed) frame. 

Euler angle ranges:

* XYZ, ZYX: phi in [-pi,   pi],   theta in [-pi/2, pi/2], psi in [-pi,   pi]  
* XZY, YZX: phi in [-pi,   pi],   theta in [-pi,   pi],   psi in [-pi/2, pi/2]
* ZXY, YXZ: phi in [-pi/2, pi/2], theta in [-pi,   pi],   psi in [-pi,   pi]

Functions for converting from one euler sequence to another are also available.

The above convention the same as the sequence used in the [Blender blenlib
code](https://github.com/blender/blender/blob/
7d641fe96810cdc2598b2f37ec4f6192e133e6d8/source/blender/
blenlib/BLI_math_euler_types.hh>)

In contrast, the 'XYZ' sequence is understood in the aerospace community as:
First rotation about Z-axis, second rotation about Y-axis, and the third
rotation about X-axis of the body frame.

The functions are available in _C_, _Fortran_, and _python_. The source files
are in `c/src`, `fortran/src`, and `python/rotlib`, respectively.

## Installation

### C version

A makefile is available for the GCC  compiler in `c/build`. The command `make
lib` will create a static library `librotlib.a` put it in the `c/lib`
directory. A calling program can link appropriately to this library.

Tests are available in `c/test`. The command `make test` will build the tests
as an executable `c/test/test_main`.

Documentation is generated using [Doxygen](https://www.doxygen.nl). The command
`make doc` will build the HTML documentation in `docs/c_api`.

The function `aa_rand()` requires a random number generator. In the code, the
library functions `srand()` and `rand()` have been used as the random number
generation is not crucial for the rest of the functions. If a better random
number generator is required, the files `c/src/ran_num.c` and `c/src/ran_num.h`
provide an interface to the random number generation routines of the [Intel
Math Kernel Library
(MKL)](https://www.intel.com/content/www/us/en/developer/tools/oneapi/onemkl.html).
The implementation of `aa_rand()` may be modified (as well as the makefile) to
incorporate the routines from MKL.

### Fortran version

A makefile is available for the gfortran compiler in `fortran/build`. The
command `make lib` will create a static library `librotlib.a` put it in the
`fortran/lib` directory. A calling program can link appropriately to this
library.

Tests are available in `fortran/test`. The command `make test` will build the tests
as an executable `fortran/test/test_main`.

Documentation is generated using
[FORD](https://forddocs.readthedocs.io/en/stable).  The command `make doc` will
build the HTML documentation in `docs/fortran_api`.

Fortran intrinsic functions are used for random number generation which are good
enough for our purposes.

### Python version

The module `rotlib` can be installed using `pip`.

```bash
pip install 
```

A makefile for [Sphinx](https://www.sphinx-doc.org/en/master/index.html)
autogenerated HTML documentaion is available in `python/docs`.

Tests are available in `python/tests`. The file `python/pyproject.toml`
contains directives for [ruff](https://docs.astral.sh/ruff),
[pytest](https://docs.pytest.org/en/stable/), and [tox](https://tox.wiki/en/4.60.0).

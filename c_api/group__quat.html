const double angvel[3],
const bool world,
double qdot[4] )

Calculates the time derivative of a unit quaternion from angular velocity.

Let A (world frame) and B (body frame) be reference frames such that an active rotation in A by a unit quaternion q aligns its basis vectors with those of frame B. Let ang_vel be the angular velocity of B relative to A resolved in A (or B). The quantity returned is the time derivative of q.

qdot must not overlap with angvel.

Parameters
[in]qA unit quaternion. An active rotation of frame A by q aligns it with frame B.
[in]angvelAngular velocity of frame B relative to frame A resolved in A if world=true, or in B otherwise.
[in]worldIf true, the angular velocity is resolved in frame A (world frame), else, it is resolved in frame B (body frame).
[out]qdotTime derivative of q.

◆ quat_deriv_from_angvel_mat()

void quat_deriv_from_angvel_mat ( const double q[4],
const bool world,
double * mat )

Returns the matrix mapping the angular velocity to the time derivative of a unit quaternion.

Let A (world frame) and B (body frame) be reference frames such that an active rotation in A by a unit quaternion q aligns its basis vectors with those of frame B. Then the matrix M returned is such that qdot_i = M_ij * omega_j, where omega_j is the angular velocity of B relative to A resolved in A (or B) and qdot_i is the time derivative of q.

mat must not overlap with q.

Parameters
[in]qA unit quaternion.
[in]worldIf true, the angular velocity is resolved in frame A (world frame), else, it is resolved in frame B (body frame).
[out]matThe 4 x 3 quaternion derivative matrix.

Calculates the angular velocity from a unit quaternion and its time derivative.

Let A (world frame) and B (body frame) be reference frames such that an active rotation in A by a unit quaternion q aligns its basis vectors with those of frame B. Let qdot be the time derivative of q. The quantity returned is the angular velocity of B relative to A resolved in A (or B).

angvel must not overlap with qdot.

Parameters
[in]qA unit quaternion.
[in]qdotTime derivative of q. In general, this is not a unit vector. Note that qdot is orthogonal to q, i.e. q . qdot = 0.
[in]worldIf true, the angular velocity is resolved in frame A (world frame), else, it is resolved in frame B (body frame).
[out]angvelAngular velocity.

Performs spherical linear interpolation between two unit quaternions following the shortest path. The second endpoint may be negated to select the shortest path. At a relative orientation (physical) of exactly pi, two equally short paths exist; the supplied endpoint signs determine which is selected.

q may coincide exactly with q1, but must not partially overlap it.

Parameters
[in]q1A unit quaternion.
[in]q2Another unit quaternion.
[in]tInterpolation factor, 0 <= t <= 1 specifying the interpolation point..
[out]qInterpolated unit quaternion.

◆ quat_rotmat()

void quat_rotmat ( const double q[4],
double * rotmat )

Calculates the rotation matrix corresponding to a unit quaternion.

For a column vector v of length 3, the rotated vector v' = R v, where R is the returned matrix. The components of v and v' are expressed in the same fixed orthonormal basis. For a row vector, the equivalent rotated vector v' = v R^T.

Parameters
[in]qA unit quaternion.
[out]rotmat3 x 3 rotation matrix.

◆ quat_shiftmat()

void quat_shiftmat ( const double q[4],
const bool forward,
double * shiftmat )

Calculates the shifter matrix corresponding to a unit quaternion.

Parameters
[in]qA unit quaternion.

The orientation of frame B relative to frame A is specified by a unit quaternion q, such that an active rotation in A of its basis vectors aligns them with those of B. The shifter matrix S transforms the components of a fixed vector resolved in A to those resolved in B or vice-versa according to v_B_i = S_ij * v_A_j or v_A_i = S_ij * v_B_j.

Parameters
[in]forwardIf true, transform components from A to B. If false, transform components from B to A.
[out]shiftmat3 x 3 shifter matrix.

int aa_fix ( double axis[3],
double * angle,
const bool normalize_axis )

For a given orientation in axis-angle representation, returns a modified axis and angle to ensure that angle lies in [0, pi] while preserving the rotation.

axis and angle must not overlap with each other.

Parameters
[in,out]axisin: A non-zero 3-vector representing the axis of rotation.
out: If normalize_axis=true, the normalized axis. If normalize_axis=false, it has the same magnitude as axis and may need to be normalized before using other axis-angle functions.
[in,out]anglein: Angle in radian.
out: Modified angle in radian (lies in [0, pi]).
[in]normalize_axisWhether to normalize axis to a unit vector.
Returns
EXIT_FAILURE if axis is a zero-vector, EXIT_SUCCESS otherwise. No changes to axis or angle is made is case of EXIT_FAILURE.

Extracts axis and angle from a rotation matrix.

If rotmat is an identity matrix, the axis returned is [1,0,0]. If the angle is exactly pi, either sign of the axis is valid.

axis and angle must not overlap with each other or with rotmat.

Parameters
[in]rotmat3 x 3 rotation matrix. Must be orthonormal with determinant equal to one.
[out]axis[3,] Unit vector along the axis.
[out]angleAngle of roation in radian within [0, pi].

◆ aa_rotmat()

void aa_rotmat ( const double axis[3],
const double angle,
double * rotmat )

Calculates the matrix for an active rotation about axis through angle, with positive angles following the right-hand rule.

For a column vector v of length 3, the rotated vector v' = R v, where R is the returned matrix. The components of v, v', and axis are expressed in the same fixed orthonormal basis. For a row vector, the equivalent rotated vector v' = v R^T.

rotmat must not overlap with axis.

Parameters
[in]axisA 3-vector representing a unit vector along the axis of rotation.
[in]angleAngle in radian. Positive angles follow the right-hand rule.
[out]rotmat3 x 3 rotation matrix.

Transforms second-order tensor components between frames A and B.

The orientation of B relative to A is specified by axis and angle, with axis expressed in A and positive angles following the right-hand rule. This orientation is used for both transformation directions. The tensor remains unchanged; only its components are expressed in a different frame.

Ashift must not overlap with A.

Parameters
[in]AComponents of a 3 x 3 second-order tensor, expressed in A if forward is true, or in B otherwise.
[in]axis[3,] Unit vector along the axis expressed in A, regardless of forward.
[in]angleAngle specifying the orientation of B relative to A, in radians. Positive angles follow the right-hand rule.
[in]forwardIf true, transform components from A to B. If false, transform components from B to A.
[out]Ashift3 x 3 array containing the components of the second-order tensor expressed in B if forward is true, or in A otherwise.

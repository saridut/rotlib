◆ isclose()

bool isclose ( const double a,
const double b,
const double rel_tol,
const double abs_tol )

Checks whether two floating-point numbers are close within relative or absolute tolerance.

The comparison is symmetric. The absolute difference is compared with abs_tol and with rel_tol times the magnitude of either operand. Meeting any one of these criteria is sufficient.

Equal values, including infinities of the same sign, are close. Unequal non-finite values and comparisons involving NaN return false.

Parameters
[in]aA floating-point number.
[in]bAnother floating-point number.
[in]rel_tolRelative tolerance. Must be >= 0.
[in]abs_tolAbsolute tolerance. Must be >= 0.
Returns
true if a and b are close, otherwise false.

const double * B,
const bool transB,
double * C )

Multiplies two matrices A and B according to one of the following forms: (1) AB, (2) A^TB, (3) AB^T, or (4) A^TB^T and puts the result in C.

Dimensions of A and B describe stored matrices, e.g. nrows_A and ncols_A are the dimensions of A before transposition. Even if transA is true, the stored matrix is not changed, rather different strides are used to handle the transposed case.

After applying transA, A is interpreted to be an m x nA array. Similarly, after applying transB, B is viewed as an nB x p array. Compatilibity requires that nA = nB. Calls with non-compatible matrices will print an error message and abort.

C must not overlap with A or B and must provide writeable storage for at least m*p doubles, where m and p depend on the transpose flags.

Parameters
[in]nrows_ANumber of rows of A. Must be > 0.
[in]ncols_ANumber of columns of A. Must be > 0.
[in]AMatrix of size nrows_A x ncols_A.
[in]transAtrue if A should be transposed, false otherwise.
[in]nrows_BNumber of rows of B. Must be > 0.
[in]ncols_BNumber of columns of B. Must be > 0.
[in]BMatrix of size nrows_B x ncols_B.
[in]transBtrue if B should be transposed, false otherwise.
[out]CResult of the multiplication.

const double * b,
double * c )

Multiplies matrix A and vector b according to one of the following forms: (1) Ab or (2) A^Tb and puts the result in c.

Dimensions of A describe stored matrices, e.g. nrows and ncols are the dimensions of A before transposition. Even if transA is true, the stored matrix is not changed, rather different strides are used to handle the transposed case.

If transA is false, b must be of size ncols and c of size nrows. If transA is true, b must be of size nrows and c of size ncols.

c must not overlap with A or b and must provide writeable storage for at least nrows (or ncols) doubles, depending on transA.

Parameters
[in]nrowsNumber of rows of A. Must be > 0.
[in]ncolsNumber of columns of A. Must be > 0.
[in]AMatrix of size nrows x ncols.
[in]transAtrue if A should be transposed, false otherwise.
[in]bVector of size ncols if transA is false, otherwise of size nrows.
[out]cResult of the multiplication. Must be of size nrows if transA is false, otherwise of size ncols.

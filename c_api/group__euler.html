Transform second-order tensor components between frames A and B.

The orientation of B relative to A is specified by Euler angles. This orientation is used for both transformation directions. The tensor remains unchanged; only its components are expressed in a different frame.

Ashift must not overlap with A.

Parameters
[in]A3 x 3 second-order tensor. Expressed in A if forward is true, or in B otherwise.
[in]eulerEuler angles.
[in]seqES_XYZ | ES_XZY | ES_YXZ | ES_YZX | ES_ZXY | ES_ZYX.
Sequence for Euler angles.
[in]worldWhether the Euler angles are with respect to the world frame or not.
[in]forwardIf true, transform components from A to B. If false, transform components from B to A.
[out]Ashift3 x 3 array containing the components of the same tensor expressed in B if forward is true, or in A otherwise.

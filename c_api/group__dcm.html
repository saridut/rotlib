◆ dcm_from_frames()

void dcm_from_frames ( const double * A,
const double * B,
double * dcm )

Returns the direction cosine matrix of frame B with respect to frame A, where the bases of the frames are resolved in an underlying fixed frame F. If F coincides with A, then A reduces to an identity matrix.

Direction cosine matrix must not overlap with A or B.

Parameters
[in]A3 x 3 array. The rows of A represent the orthonormal basis vectors of a right-handed frame A resolved in F.
[in]B3 x 3 array. The rows of B represent the orthonormal basis vectors of a right-handed frame B resolved in F.
[out]dcm3 x 3 direction cosine matrix of frame B with respect to frame A.

Rotates vectors by a direction cosine matrix.

Let D be the direction cosine matrix of frame B relative to frame A. Vectors resolved in A are rotated such that the bases of A align with those of B, when all the bases are resolved in A.

vrot must not overlap with v.

Parameters
[in]nNumber of rows of v.
[in]vn x 3 array whose rows are the components of vectors to rotate.
[in]dcm3 x 3 direction cosine matrix.
[out]vrotn x 3 array whose rows are the components of rotated vectors.

Let D be the direction cosine matrix of frame B relative to frame A. The rotation matrix R corresponding to D rotates vectors resolved in A such that the bases of A align with those of B, when all the bases are resolved in A.

const double * dcm,
const bool forward,
double * Ashift )

Transform second-order tensor components between frames A and B.

The orientation of B relative to A is specified by Direction cosine matrix. This orientation is used for both transformation directions. The tensor remains unchanged; only its components are expressed in a different frame.

Ashift must not overlap with A.

Parameters
[in]A3 x 3 second-order tensor. Resolved in A if forward is true, or in B otherwise.
[in]dcm3 x 3 direction cosine matrix of frame B with respect to frame A.
[in]forwardIf true, transform components from A to B. If false, transform components from B to A.
[out]Ashift3 x 3 second-order tensor whose components are expressed in B if forward is true, or in A otherwise.

Returns the shifter matrix corresponding to a direction cosine matrix.

Let D be the direction cosine matrix of frame B relative to frame A. The shifter matrix S corresponding to D transforms components of vectors (or tensors) resolved in A to those in B (or vice-versa).

shiftmat must not overlap with Direction cosine matrix, regardless of forward.

Parameters
[in]dcm3 x 3 direction cosine matrix.
[in]forwardIf true, transform components from A to B. If false, transform components from B to A.
[out]shiftmat3 x 3 shifter matrix.

public subroutine align(v, old, new, valigned)

Rotate vectors such that a set of at most three mutually orthogonal unit vectors aligns with another set of mutually orthogonal unit vectors. The two sets of mutually orthogonal unit vectors must contain the same number of unit vectors.

Read more…

Arguments

Type IntentOptional Attributes Name
real(kind=rp), intent(in), dimension(:,:) :: v

(3,m). Vectors to align.
real(kind=rp), intent(in), dimension(:,:) :: old

(3,n). A set of at most three mutually orthogonal unit vectors. n must be one of 1, 2 or 3. If n = 3, the three unit vectors must form a right-handed basis.
real(kind=rp), intent(in), dimension(:,:) :: new

(3,n). Another set of mutually orthogonal unit vectors of the same shape as old. If n = 3, the three unit vectors must form a right-handed basis.
real(kind=rp), intent(out), dimension(:,:) :: valigned

(3,m). Aligned vectors, of the same shape as v. The components in out are resolved in the same underlying basis as the vectors in v.

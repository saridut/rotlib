rotlib.rotlib.align(v, old, new)[source]#

Rotate vectors such that a set of at most three mutually orthogonal unit vectors aligns with another set of mutually orthogonal unit vectors. The two sets of mutually orthogonal unit vectors must contain the same number of unit vectors.

v, old, and new store their constituent vectors row-wise, with all vectors resolved in the same fixed underlying basis.

The vectors in v are rotated using a rotation matrix R such that new[i,:] = old[i,:] @ R.T, for each unit vector i (stored in the i th row), with the single vector (n=1) case treated equivalently.

If old is a single vector, a unique rotation cannot be defined. In this case, the shortest rotation mapping old to new is chosen. For anti-parallel directions, this is a half-turn about a chosen axis perpendicular to old.

Parameters:
v(3,) | (m,3) ndarray

Vectors to align.

old(3,) | (1,3) | (3,1) | (n,3) ndarray

A set of at most three mutually orthogonal unit vectors. A single unit vector can be of shape (3,), (1,3), or (3,1). Else n must be 2 or 3. If n = 3, the three unit vectors must form a right-handed basis.

new(3,) | (1,3) | (3,1) | (n,3) ndarray

Another set of mutually orthogonal unit vectors of the same shape as old. If n = 3, the three unit vectors must form a right-handed basis.

Returns:
outndarray

Aligned vectors. out is of the same shape as v. The components in out are resolved in the same underlying basis as the vectors in v.

rotlib.rotlib.quat_deriv_to_angvel_mat(q, world=False)[source]#

Returns the matrix mapping the derivative of a unit quaternion to angular velocity.

Let A (world frame) and B (body frame) be reference frames such that an active rotation in A by a unit quaternion q aligns its basis vectors with those of frame B. Then the matrix M returned is such that omega_i = M_ij * qdot_j, where omega_i is the angular velocity of B relative to A resolved in A (or B) and qdot_j is the time derivative of q.

Parameters:
q(4,) ndarray

Unit quaternion.

worldbool

If True, the angular velocity is resolved in frame A (world frame), else, it is resolved in frame B (body frame). Default is False.

Returns:
(3,4) ndarray

Angular velocity matrix.

rotlib.rotlib.quat_shiftmat(q, forward=False)[source]#

Returns the shifter matrix corresponding to a unit quaternion.

The orientation of frame B relative to frame A is specified by a unit quaternion q, such that an active rotation in A of its basis vectors aligns them with those of B. The shifter matrix S transforms the components of a fixed vector resolved in A to those resolved in B or vice-versa according to v_B_i = S_ij * v_A_j or v_A_i = S_ij * v_B_j.

Parameters:
q(4,) ndarray

Unit quaternion.

forwardbool

If True, transform components from A to B. If False, transform components from B to A. Default is False.

Returns:
(3,3) ndarray

Shifter matrix.

rotlib.rotlib.quat_from_any(orientation)[source]#

Converts an orientation to unit quaternion from either of the following: (1) Quaternion, (2) Euler angles, (3) Axis-angle, or (4) Direction cosine matrix.

Parameters:
orientationdict

The keys and values are:

  • ‘repr’ = 'quat' | 'euler' | 'axis_angle' | 'dcm'

  • ‘quat’ = (4,) ndarray representing a unit quaternion.

  • ‘euler’ = (3,) ndarray

  • ‘seq’ = 'XYZ' | 'XZY' | 'YXZ' | 'YZX' | 'ZXY' | 'ZYX'

  • ‘world’ = True | False

  • ‘axis’ = (3,) ndarray representing a unit vector.

  • ‘angle’ = float

  • ‘dcm’ = (3,3) ndarray representing a direction cosine matrix.

For any value of ‘repr’, only the relevant keys are accessed, the rest are ignored. E.g., if ‘repr’ = 'quat', only the ‘quat’ key is necessary, but for ‘repr’ = 'euler', the required keys are ‘euler’, ‘seq’, and ‘world’.

Returns:
(4,) ndarray

Unit quaternion.
